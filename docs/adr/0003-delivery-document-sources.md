# ADR 0003: Issue tracker for Grove delivery

Grove's spec, tickets and review requirements need to be reachable from the PR throughout delivery. The deployment's global AGENTS.md names the tracker and tools. The issue body is the authoritative spec for one PR. Track same-PR slices as checklist items and create linked issues for slices that need independent tracking. Markdown issue references represent membership and prerequisites across forges.

Keep long-lived decisions in repository ADRs so they follow the code and branch. Keep decisions specific to a PR in its spec issue. Research findings continue to be archived in FlickNote.

This supersedes FlickNote ADR #2699 for new specs, tickets and ADRs. Existing records remain at their original locations.
